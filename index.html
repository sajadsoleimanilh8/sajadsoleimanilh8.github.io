Sajad YouTube Tools

A personal tool for managing my own YouTube channels.

This is a private tool that I, the channel owner, run on my own computer. It connects to my own YouTube channels through the YouTube Data API and the YouTube Analytics API so I can:

  • read my channels' statistics and analytics,
  • read the comments on my videos,
  • upload videos and edit their titles, descriptions and thumbnails when I ask it to.

The channels it is used with:

  • RevealYT (@iosReveall)
  • END WORLD (@endworld-h2k)

It is not a public service and is not offered to other users.
